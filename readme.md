# Factorio Standard Library: Legacy Updated

Provides reusable helpers for events, data-stage prototypes, positions, areas, tables, logging and player data. This port updates LuaObject validation, entity protection and event invalidation handling for Factorio 2.1.24 or later while retaining the library’s module layout.

Dependent mods should declare `stdlib-legacy-updated >= 2.1.2` and import through this mod’s namespace:

```lua
local Event = require("__stdlib-legacy-updated__/stdlib/event/event")
```

Original authors and maintainers include Afforess, Jackie P. Mueller, Goakiller900 and the Factorio modding community. Original licensing and attribution files are retained. See the [original Mod Portal entry](https://mods.factorio.com/mod/stdlib), [original library source](https://github.com/Afforess/Factorio-Stdlib) and [previous continuation](https://github.com/goakiller900/stdlib2).
